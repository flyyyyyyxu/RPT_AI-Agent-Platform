# Agent 基建平台 · 前端框架原型

本阶段提供全局导航、设计规范样板页、4 个 Agent 的演示数据，以及「内部制度问答助手」的基础能力完整主路径：新建、配置、调试、评测、发布、监控和回退。Trace 与 bad case 及其他生产骨架能力仍为占位内容。

在本目录运行 `npm install`、`npm run build`。构建完成后，直接打开 `dist/index.html`；页面通过 Hash 路由切换，刷新不会请求服务端。`npm run dev` 可用于本地开发。

## 版本模型

- 每个版本都是不可修改的快照（模型、Prompt、步骤、工具、知识版本、输出格式）。只有候选版本（草稿 / 待发布）可以编辑。
- 线上、历史版本只读；要修改时在构建页「基于 vX 新建草稿」。
- 候选版本需依次完成：保存配置 → 调试 → 至少一个评测集，才能发布。保存了新的修改后，调试和评测结果会失效。
- 发布和回退都只改变生产环境的「线上指向」。只有曾经上线过的版本可以回退，草稿、待发布和灰度中的版本不能回退。
- 相关逻辑集中在 `src/app/versions.ts` 和 `src/app/DemoProvider.tsx`。

## 数据与存储

页面数据为 mock，集中在 `src/data/mock.ts`，4 个 Agent 各有自己的配置、调试预设、评测集和监控数据。演示进度保存在浏览器存储中（键名 `agent-platform-demo-v2`）。数据结构变化时要同步提升 `src/app/storage.ts` 里的版本号，旧存档会被自动丢弃。页面出错时只替换内容区，可点「重置演示」恢复。Google Fonts 无法访问时会使用系统字体。
